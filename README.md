# Unix/Linux Fundamentals

Foundation course in Unix/Linux systems. Starting point for system administration and command-line proficiency.

## Topics

- Linux file system navigation
- Basic commands and utilities
- File permissions and ownership
- Text processing tools
- System fundamentals

## Skills

- Command-line proficiency
- File system understanding
- Basic system administration
- Text manipulation
- Shell usage

## Why This Matters

Linux mastery is non-negotiable for cybersecurity:
- Most security tools run on Linux
- Many targets are Linux servers
- Kali Linux is primary pentesting OS
- Post-exploitation on *nix systems
- Understanding permissions and privilege escalation

This is where it all starts - can't do security without solid Linux fundamentals.
